# Andariegos Cocina de Mundo — V0.3

Rebuild visual/frontend sobre el repositorio actual.

## Principios
- Restaurante primero.
- Voz del restaurante: “te invitamos”.
- Artesanal en el lenguaje, preciso en la ejecución.
- Hoja / Madera como temas visuales.
- Navegación abierta/cerrada únicamente al pulsar el logo.
- Carrito único y global.
- Menú enfocado en rapidez.
- Simijacá como territorio y experiencia, no como agencia turística.
- No se inventan productos ni premios.

## Instalación
1. Reemplaza los archivos del proyecto con esta versión.
2. Conserva `public/images` y sus fotos actuales.
3. No subas `.env`, `.env.local`, `node_modules` ni `.next`.
4. Ejecuta `npm install`.
5. Ejecuta `npm run dev`.

Esta V0.3 todavía es frontend/local. Supabase, OTP real, dashboard real, RLS y persistencia se conectan después de validar la experiencia visual.
